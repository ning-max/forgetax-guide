# ForgeTax 冲 +99：经济优先逐日攻略

单文件 HTML 攻略，下载后用现代浏览器打开。

## 下载与打开

1. 在本仓库首页找到右侧 **Releases（发布）**，打开 **v5**。手机端可从仓库的 Releases 入口进入。
2. 在 **Assets（附件）** 中点击 **ForgeTax_v5.html** 下载。
3. 用 Edge、Chrome 等现代浏览器打开下载的 HTML 文件。无需安装额外软件。

也可以在仓库首页点击绿色 **Code → Download ZIP**，解压后打开 `ForgeTax_v5.html`。

## 包含内容

- 第 1—21 天的每日计划和贡品安排。
- 最终 8 件遗物清单与过渡遗物记录。
- 贡品预算计算器、刷新建议与幽灵商人购买建议。
- 遗物勾选、每日备注和展开状态保存在当前浏览器本地；更换浏览器或清理网站数据后，记录可能无法保留。

## 版本说明

本仓库中的 `ForgeTax_v5.html` 来自提供的 v5 原始文件，仅简化文件名，未修改攻略内容。游戏机制与数值以游戏实际版本为准，本攻略不保证每局达成 +99。
